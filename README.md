# Kakeibo - シンプル家計簿

マネーフォワードの代わりに使える、ローカル完結の家計簿アプリです。
インストール不要・外部通信なし。データはブラウザの localStorage に保存されます。

## 使い方

`index.html` をブラウザ（Chrome / Edge など）で開くだけで使えます。

## 機能

- **ダッシュボード**: 月の収入・支出・収支・資産合計、カテゴリ別ドーナツチャート、日別支出グラフ、予算の進捗
- **取引**: 収入・支出・振替（口座間移動）の記録、検索・フィルタ、編集・削除
- **カレンダー**: 日ごとの収支を一覧、クリックでその日の取引を追加
- **予算**: カテゴリごとの月間予算と使用率バー
- **固定費**: 家賃・給与・サブスクなどを毎月自動記録（停止/再開も可）
- **設定**: カテゴリ・口座の追加/削除、CSVエクスポート/インポート、サンプルデータ
- **ダークモード**: ヘッダー右上の 🌙 で切替

## CSVインポート

- このアプリが出力する汎用CSV（日付,種別,金額,カテゴリ,口座,メモ）
- マネーフォワードMEのCSV（計算対象/日付/内容/金額（円）/保有金融機関/大項目/中項目/振替）をそのまま取り込めます。
  - 金額が負 → 支出、正 → 収入として登録
  - 「計算対象=0」「振替=1」の行はスキップ
  - 未登録のカテゴリ・口座は自動作成

## 注意

- データはブラウザごとに保存されます。ブラウザのデータ削除や別PCでは引き継がれないため、CSVエクスポートでバックアップしてください。
