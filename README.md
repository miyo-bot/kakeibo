# Kakeibo - 毎日使える家計簿

マネーフォワードMEの代替を目指す、ローカル完結の家計簿アプリです。
インストール・ログイン不要。データはブラウザの IndexedDB（フォールバック: localStorage）に保存され、外部通信はありません。

## 使い方

index.html をブラウザ（Chrome / Edge / Safari）で開くだけで使えます。
スマホでも快適に使えるようモバイルファーストで設計しています。

## 主な機能

| 画面 | 内容 |
|---|---|
| ホーム | 総資産・現金預金・投資・カード残高・今月収支・前月比・予算残額・月末予想残高をカード表示（並び替え可）。カテゴリ別ドーナツ・日別支出・月別収支グラフ |
| 取引 | 支出/収入/振替の記録・編集・削除。店舗名・タグ・除外フラグ・メモ対応。複合フィルタ（期間・金額・店舗・カテゴリ・口座・タグ）と一括編集（Undo可） |
| 分析 | オンデバイスAIによる自動インサイト（前月比・予算超過見込・固定費・値上げ・残高予測）。自然言語で質問できる安全なQuery Layer |
| 予算 | カテゴリ別月間予算。消化率・1日あたり使用可能額・月末予測・80%警告 |
| カレンダー | 日別収支を一覧。日付タップでその日に追加 |
| 資産 | 口座別残高・種別（現金/銀行/クレカ/投資/電子マネー）。投資口座は評価額を記録して損益を表示。月次資産推移グラフ |
| 固定費 | 定期収支の自動記録（支出/収入/振替）。取引履歴から固定費・サブスクを自動検出して登録提案 |
| データ | CSVインポート（列マッピング・プレビュー・重複スキップ・取り消し）。CSV/JSONエクスポート、JSON復元 |
| 設定 | カテゴリ・口座・学習ルール・定型取引の管理。サンプルデータ・全削除 |

## カテゴリ自動分類

取引の店舗名から自動でカテゴリを推定します。優先順位:

1. ユーザー定義ルール（カテゴリ修正時に学習）
2. 過去取引（同じ店舗の直近カテゴリ）
3. 店舗辞書（約150キーワード）
4. その他

外部AI APIがなくても基本分類は動作します。

## データの保存先

- IndexedDB を主に使用（大容量・100,000件規模に対応）
- IndexedDB が使えない場合は localStorage にフォールバック
- 保存はデバウンス（250ms）で自動実行

## CSVインポート対応

- このアプリのエクスポートCSV
- マネーフォワードMEのCSV（計算対象/日付/内容/金額（円）/保有金融機関/大項目/中項目/振替）
- 汎用CSV（列マッピングを自動推定、手動修正可）
- 重複は「日付+種別+金額+店舗+メモ+口座」で検出してスキップ
- インポートはバッチ単位で記録し、後から取り消せます

## 金融機関連携

銀行・カード・証券サイトのスクレイピングは行いません。
js/providers.js のアダプタ方式で、公式APIが提供された金融機関から順次追加できる設計です。
現状は「CSVインポート」「手動入力」に対応。

## テスト

    node tests/run.mjs

収支計算・振替・固定費・自動分類・CSV・一括更新・予算・資産・予測・自然言語検索・マイグレーションをカバーしています。

## ファイル構成

    index.html        骨格・モーダル・シート
    styles.css        モバイルファーストのスタイル（ダークモード対応）
    js/store.js       データ層（IndexedDB/localStorage・インデックス・マイグレーション）
    js/classify.js    カテゴリ自動分類（ルール/履歴/辞書）
    js/insights.js    分析エンジン（固定費検出・予算ペース・残高予測・インサイト）
    js/nlq.js         自然言語検索（安全なQuery Layer）
    js/csv.js         CSVパース・列マッピング・インポート
    js/providers.js   金融機関連携アダプタ層
    js/charts.js      SVGチャート（ドーナツ/棒/折れ線）
    js/app.js         アプリコア（ナビ・モーダル・トースト・初期化）
    js/views.js       画面描画
    tests/run.mjs     ユニットテスト

## 注意

- データはブラウザごとに保存されます。ブラウザのデータ削除や別PCでは引き継がれないため、JSON/CSVエクスポートでバックアップしてください。
- 外部AI APIは未接続です。分析・検索はすべてローカルで動作します。
